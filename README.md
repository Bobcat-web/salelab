# salelab

Одностраничный промо-лендинг проекта salelab — диагностики потерь заявок и контактов в воронке продаж онлайн-школ.

## Стек

- React
- JavaScript
- Vite

## Запуск проекта из GitHub

Для работы понадобится [Node.js](https://nodejs.org/) версии `20.19+` или `22.12+`.

Склонируйте репозиторий:

```bash
git clone https://github.com/Bobcat-web/salelab.git
cd salelab
```

Установите зависимости:

```bash
npm install
```

Запустите локальный сервер:

```bash
npm run dev
```

После запуска откройте в браузере адрес, показанный в терминале. По умолчанию:

```text
http://localhost:5173/
```

## Проверка production-сборки

```bash
npm run build
npm run preview
```

Собранные файлы появятся в папке `dist`.
